## 安装与升级

1. 解压产物，把 `MosBot.app` 移到 `/Applications`（或其它可写位置）。
2. 由于是 ad-hoc 签名，第二台 Mac 首次打开需右键“打开”。
3. 通过系统浏览器 OAuth 登录；凭据经 `safeStorage` 保存在 macOS 钥匙串。
4. 升级时退出应用、替换 `MosBot.app` 后重新打开。本地状态原地升级（v1 → v2）；文档损坏时回退到备份而不是显示默认值。

## 已知限制

- **Gatekeeper / Developer ID**：ad-hoc 签名，`spctl` 拒绝，第二台 Mac 需右键打开；无公证票据。
- **电脑非抢占租约**：移出首版范围。后来者可抢占；客户端正确显示“他人控制”，被踢后回到只读。
- **产物来源字段**：`/api/files` 没有来源消息字段，资料库无法显示产物来自哪条消息（Issue #15）。
- **插件禁用状态**与**未配置模型环境**未在部署上验证（Issue #17、#16）。
- **分发格式**：仅 ZIP，无 DMG。
- **M6**：部署协议层已具备群聊；该无头部署的语音唤醒不可用。两者都不在本候选内。
- 通知点击修复后尚未再次做真实鼠标点击；同一 IPC 路径由 `scripts/gui-pending-open.mjs` 覆盖。
